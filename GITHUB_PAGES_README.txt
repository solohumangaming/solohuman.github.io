SOLO HUMAN — GITHUB PAGES

This package is the "Download Updated Solo Human Website" design prepared for GitHub Pages.
The original visual design has not been intentionally changed.

UPLOAD:
1. Create a GitHub repository. For a personal site, name it: YOURUSERNAME.github.io
2. Set the repository to Public if you are using GitHub Free.
3. Extract this ZIP.
4. Upload ALL files from this folder directly into the repository root.
   index.html must be in the root (not inside another folder).
5. Open repository Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select branch: main, folder: / (root), then Save.
8. Wait for GitHub Pages to publish the site.

YOUR SITE:
https://YOURUSERNAME.github.io/

NOTES:
- .nojekyll is included for straightforward static hosting.
- 404.html is included for missing-page handling.
- The site is static HTML/CSS/JS, so GitHub Pages can host it directly.
- Replace placeholder # links in index.html/script.js with your own official or legally shareable links.
